CONTEXT AND INTENT
The lane fixes the continue-as-new epoch gate in the aion engine (crates/aion, package name aion-rs):
- `record_continuation` (crates/aion/src/runtime/nif_continue_as_new.rs) refuses the WorkflowContinuedAsNew terminal when the engine-task epoch is closed, because the successor that terminal obliges is already refused at start_continuation_replacement — an ungated terminal severs the continuation chain.
